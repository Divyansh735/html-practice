# 📊 HTML Table Project

This is a simple HTML project that displays a styled table of employee data using basic HTML and CSS.

---

## 🚀 Features

- Clean table structure using `<table>`, `<thead>`, and `<tbody>`
- Styled using internal CSS
- Zebra striping for better readability
- Highlighted header and total row
- Centered table layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
